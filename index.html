How to reset permissions?
  • Chrome / Edge (Android/ডেস্কটপ): ঠিকানা বারের পাশে 🔒/⚙️ আইকনে ক্লিক করুন → "Site settings" → Location → "Allow" নির্বাচন করুন, তারপর পেজ রিফ্রেশ করুন।
  • Firefox: ঠিকানা বারের 🔒 আইকনে ক্লিক করুন → "Connection" / "Permissions" → Location-এর পাশে "Clear permission" → রিফ্রেশ করুন।
  • Safari (iPhone/iPad): Settings → Safari → Location → এই সাইটটি খুঁজে "Allow" করুন।
  • Safari (Mac): Safari → Settings → Websites → Location → এই সাইটের জন্য "Allow" নির্বাচন করুন।
তারপর "Try again" বাটনে ক্লিক করুন।
